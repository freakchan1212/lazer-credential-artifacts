## 论文引用

论文应引用与实际提交稿件相对应的固定材料版本。
GitHub 地址用于访问代码、补充材料及复现说明；
Zenodo 的具体版本 DOI 用于标识论文所依据的材料快照。

正式发表后，补充论文的正式书目信息和论文 DOI。
如期刊另有补充材料提交要求，按期刊要求同时提交。
