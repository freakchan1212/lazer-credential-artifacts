1. 原附件1、2、3自带清单分别核验709、863、54份文件，全部一致。
2. 附件1整包位于code/，附件3整包位于evidence/；当前源码、参数、回归脚本和原证据未被旧代码包替换。附件2的数据逐字节保留在data/，原绘图源及历史说明分开放入analysis/和provenance/。
3. 当前8张PNG全部逐字节匹配V6正文5张与补充材料3张嵌图；8个SVG均无嵌入位图image节点，是真实矢量图。PNG不是改扩展名的伪SVG。
4. 运行新的独立统计入口，核对406项任务、13,972条含预热记录、7,200条正式主任务、12,480个正式计时证明；主统计和Bootstrap汇总与原附件独立统计完全一致，没有新增失败状态。辅助实验不能算作额外主实验样本。
5. 运行新的8图重绘入口成功；本机重绘图4的PNG与交付图4逐字节相同。其余重绘图可能因字体或软件版本而改变像素/文件哈希，不据此增加或更改样本；交付图仍以V6嵌图一致的文件为准。
6. data/raw的812份记录及回执与完整主实验tar归档逐字节相同，是同一批数据的两种保存方式，不能合并后重复计数。
7. 原运行器帮助入口可调用。本轮没有重新编译LaZer/HEXL/MPFR原生库，没有重跑smoke、pilot或full计时，不能声称已在本机完成整套原生实验复现。

## 旧英文稿最终代码包的处理

比较旧包project与当前附件1/source/project：680份同路径文件相同，12份不同；当前独有1份环境日志，旧包独有223份文件。旧包额外包含本机编译产物、构建缓存、旧版文档和实验；差异也包括rejection.c的浮点影子诊断/计时插桩，以及审计脚本、清单。并非所有差异都可当作无关缓存。

## 发布建议

GitHub作为统一访问入口完全可行。首页直接提供补充材料PDF，代码和数据按目录展开；不要让读者只能下载多个ZIP再自行猜测关联。建议用Git或GitHub Desktop上传整个目录，因为有较多源码和数据文件；完整ZIP也可附在Release供一次下载。

建议创建固定Release标签paper-v6-artifacts-20261027，对应此次V6材料。正式稿再修订时另建版本，不移动本文引用的标签。GitHub官方支持通过Zenodo对Release建立归档并生成DOI；可在GitHub统一入口之外增加长期引用，不需要拆开补充材料和代码。
