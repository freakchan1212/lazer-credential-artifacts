# 历史图与主实验数据附件说明

本目录保存原图与数据附件的来源信息。历史附件含7幅图、406份原始JSONL及406份回执；当前仓库已经按正文图1—5及补充图S1—S3组织8幅图。历史图号和旧独立附件名不作为当前访问入口。

主实验数据位于仓库`data/`，完整原始现场位于`evidence/`，源代码与参数位于`code/`。历史说明中的运行入口仅用于追溯；当前只读核验、统计复算、精确导出及重绘命令见根目录README。当前绘图字体与许可位于`tools/fonts/`。

原统计为7,200次主会话及12,480次全部正式计时，独立子集、影子诊断和专项回归分开统计。文件指纹及源归档标识用于确认来源，不表示增加实验样本。
