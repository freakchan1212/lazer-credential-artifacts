# 中文图与主实验数据附件

本包对应当前第二篇论文。SVG/、PDF/、PNG/各7幅，PNG与当前正文嵌图逐字节一致。图1/2为机制图，图3—7由E4既有数据生成。data/raw/含406份JSONL及406份回执；data/derived/为汇总表，data/independent_checks/为独立统计与配对块数据。

## 使用

- 查看图：直接打开PDF/或PNG/；SVG中文字为路径，修改图中文字应改绘图源程序后重绘。
- 独立统计：`python3 plot_sources/independent_recompute.py`。
- 重绘：`python3 replot.py`。
- 依赖Python、numpy、matplotlib及本机可用的中文字体，可用`LAZER_CJK_FONT=/绝对路径/字体文件`指定。选择兼容中文及数学符号（含减号）的字体。字体替代可能改变外观，原交付21幅图保持原样。

本包不分发字体文件。完整性清单名称为SHA256_MANIFEST.json，覆盖除清单自身外的全部包内文件。独立程序运行会刷新派生表，重绘会刷新图文件；如需检查交付哈希，应对新解压副本先验证再运行。

主实验原档和三种子固定币回执在电子设计工程_附件3_主实验与专项回归证据.zip；代码在电子设计工程_附件1_精简代码复现包.zip。既有统计为7,200次主计时、12,480次全部正式计时，独立诊断和专项smoke未混入。完整对应见附件导航。
