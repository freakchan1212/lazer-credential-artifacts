本轮以你上传的四个文件为输入：最新论文、两份Markdown审查和外部Word评析。最新论文的文字/表格与上轮基本相同，主要换了图1/图2及图注；本轮没有把外部报告里的肯定评价当作技术事实。

## 合并判断

| 意见 | 处理 | 原因 |
|---|---|---|
| 减少重复免责声明，突出生命周期与有效见证 | 采用 | 更有利于连贯叙事；必要前提仍在方法和实验口径处保留 |
| 增加版本映射、独立紧致化对照 | 采用并实现 | G3保留V3并加范围预检查；C3仅再加紧致化，均不用浮点判定 |
| 缓存有维度/模数/首末指纹验证 | 纠正 | 现有查找实际是指针键，靠setter/clear管理生命周期 |
| P1/P2都Z=2、R2=124×124 | 纠正 | P1 Z=1、P2 Z=2；当前填充P2 R2为122×122 |
| 三轮正反序“彻底消除”时间漂移 | 不采用 | 顺序控制与增加样本不能排除系统漂移；新增随机交错小块并保存块级比较 |
| n从30到600使样本均值与OLS(K=5.5)必然收敛 | 不采用 | 固定比较点5.5不等于真实E[K]；a+bE[K]与a+5.5b可以保持差异 |
| V4全部回退都来自正指数 | 不直接采用，补计数 | 单侧守卫的确能触发回退；原总数不能排除其他原因与确定占比 |
| MPFR只占0.03ms | 不采用，补计时 | 原结果没有这个测量；本轮影子探针记录参考路径耗时，不冒充纯超越函数微基准 |
| 改fabs一行即可安全并稳定提速 | 不采用 | 放宽定义域仍需覆盖误差；本轮主方案原MPFR判定，候选只做影子比较 |
| 用负向测试验证128-bit安全一致性 | 不采用 | 参数目标、模型成本、知识误差和实现测试是不同证据 |
| 对已发表论文打9.5分、断言本文全面领先 | 不采用 | 无统一可复核尺度；既有结果也不足以保证刊物录用 |

## 实验为何这样补

核心对照是B1、G3、C3：B1→G3回答组合计算优化是否有效；G3→C3回答无浮点条件下紧致化本身有什么收益。raw/strict分别计时，分为steady与fresh；full每格600，合计7,200条主实验。新增复用次数N、策略稳定度、相同k大小与时间、全部256集合、强制回退、固定币和候选诊断。

固定币是E4内部新测试流，不与旧E3同名种子哈希直接比较。正式运行清除测试随机源；绘图不触发额外密码实验。详细命令、每档样本数和输出解释均在代码包`README_ZH.md`。

先在本地依次跑smoke、pilot，确认通过再跑full。回传末尾打印的结果`.tar.gz`即可；随后按结果更新附录B、实验分析、图表、摘要与结论，若结果不支持预期，则修改主张而非挑选样本。

本轮没有进行整协议形式化安全证明，也没有在你的机器上重跑full。代码包的运行检查范围以`LOCAL_VALIDATION.json`为准。
