# LaZer Anonymous Credential Implementation Optimization 2026.11.01

This release accompanies the manuscript “Optimizing LaZer Anonymous Credentials for Repeated Presentation and Selective Disclosure”. It includes implementation source, supplementary materials, experimental records, Chinese figures and verification evidence.

The original main experiment contains 7,200 formal sessions. A separate 7,800-session batch reports LaZer GCC/Clang builds and Argo/PQZK-BLNS native or task-adapted configurations. Historical batches remain separate. The supplementary materials document measurement boundaries, parameter differences, encoding and resource accounting.

The LaZer B1/G3/C3 paths retain the original MPFR rejection decision. The external measurements describe the listed configurations; common hidden predicates and matched security parameters are not fully aligned. Cross-configuration differences do not establish a matched-security ranking or isolate the contribution of a single optimization.

Figures 1–5 and S1–S3 are provided in SVG, vector PDF and PNG, with plotting sources and data. A read-only verification entry checks recorded files and recomputes the current comparison summaries and block effects. Third-party source and licenses are preserved.
