# 冻结验收说明

名称：lazer基线-指标版；冻结标识：LAZER-ORIGINAL-METRICS-1.0-20261014。

## 已完成的实现

本包完整实现固定官方版本的密钥生成、盲签发P1、选择性披露与匿名出示P2。原始协议Python文件、参数文件、规范和原验证API保持原哈希；只增加性能和重试观察代码。支持用户无AVX-512的AVX2/AES/FMA机器。没有降低维度、范数、采样宽度、挑战或原128位设计目标。

截图7类性能均有实际采集代码与输出：出示生成/验证、证明字节、分侧签发时间/通信、初始化/预处理、RSS、内部重试及合法失败/预算/进程超时。六类安全项目均有证据条目：经典/量子固定模型估计、不可伪造性、匿名/不可关联、知识可靠性、零知识模拟条件。

## 从现在就明确的范围

这是一份官方匿名凭证示例的实验基线，不是整篇LaZer/BLNS论文所有功能和表格的复现。撤销、追责、会话防重放、凭证不可转让、网络部署不是原示例功能，未加入。

安全性质沿用原构造的条件性结论。通用GSA/Core-SVP模型输出成本估计，知识可靠性复算原表达式；没有把模型估计替换成全协议的安全下界。签发承诺隐藏性、BLNS带辅助原像安全及Fiat–Shamir归约在assumption_coverage.csv单列，没有用证明MLWE/Falcon代理数字冒充。

没有独立实例化匿名性、不可伪造性的全协议数值归约界，也没有推导数值ZK统计距离；本包不宣称完成了这些新理论工作。如果后续目标是用“具体安全位数”证明降参优化，必须另外完成同一模型下相关安全分析；仅本包计时和反例测试不足以支持该结论。这个边界在冻结时即已列明，不留到优化后再改口。

## 可复用的实验条件

后续比较必须固定机器、CPU affinity、编译CPU配置、上游提交、消息64B、披露[0,4,5]、密钥与对象复用策略及同样的计数/计时口径。fresh与steady不可交叉对照；需单列冷启动/setup和签发，不把这些成本转移后声称出示算法加速。
